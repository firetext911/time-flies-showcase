# Roadmap

Where Time Flies: Living Clock™ is headed. Dates are not promised, and plans may change as we learn from testing and from you.

Status key: ✅ complete · 🧪 in testing · 🔜 up next · 🗓️ planned · 💭 exploring

## Toward the first release

| Milestone | What it includes | Status |
|---|---|---|
| Foundation | App groundwork, running on iPad | ✅ |
| Always-On Clock | Full-screen clock, customization, orientations, Nightstand Mode | ✅ |
| Mountain Cabin Experience | Window scene, framed and frameless styles, rain on the glass | ✅ |
| Live Weather and Preview | ZIP-code weather, sunrise and sunset, six Weather Preview presets | 🧪 |
| Official Weather Alerts | Free official U.S. alerts, banners, details, and preferences | 🔜 |
| Pro | Free and Pro plans, purchases, and restore | 🗓️ |
| Optional community connection | Optional FireTEXT®411 account linking for authorized notices | 🗓️ |
| Premium experience | Premium landscapes, advanced glass, holiday themes, ambient sounds, smart weather notifications | 🗓️ |
| Release preparation | Performance, accessibility, privacy, and App Store review | 🗓️ |
| **App Store launch** | | 🗓️ |

## After launch

These ideas are being explored for after the first release. All would be optional and off by default where appropriate, and none would ever cover the clock.

| Idea | Status |
|---|---|
| Event countdowns (birthdays, holidays, trips) | 💭 |
| Birthday reminders | 💭 |

| Daily inspiration | 💭 |

| Joke of the Day | 💭 |

| More holiday themes | 💭 |

## Our promises won't change

- **No ads, ever,** on any plan.
- **Official weather alerts stay free.**
- **No account required** to enjoy the clock.
- **The clock always comes first.**
