## Usage rules

- The clock is always on the **left** and the tree on the **right**.
- Never redraw, recolor, stretch, crop, or rearrange the logo.
- Never alter the swallow. Do not add feet, legs, or lines.
- Never add stars, globes, or other symbols.
- Never place the logo on a busy or low-contrast background.
- Always write the product name as **Time Flies: Living Clock™**. Never use ®.
